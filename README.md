# YWT目標達成アプリ）

## 概要
「達成したい目標」と、それに対する日々の活動記録である「YWT（やったこと・わかったこと・次やること）」を紐づけて管理できるWebアプリケーションです。
日々の学習の進捗を可視化し、次のアクションを明確にするため、モチベーションを維持するために開発しました。

## 主な機能
- **目標管理(Goal)機能**
  - 新規目標の設定、アクティブな目標の切り替え
- **YWT活動記録（Post）機能**
  - やったこと（Y）、わかったこと（W）、次やること（T）の投稿・編集・削除
  - 投稿日時の自動記録（タイムゾーン考慮）
- **データ連動機能**
  - 選択中の目標に紐づくYWTだけを絞り込んで表示

## 🛠️ 使用技術（Tech Stack）
- **バックエンド**: Python, Flask
- **データベース**: PostgreSQL, Flask-SQLAlchemy, Flask-Migrate
- **フロントエンド**: HTML, CSS, Jinja2テンプレート
- **環境管理**: Poetry
- **バージョン管理**: Git, GitHub

## 🗄️ データベース設計（テーブル構造）
### Goal（目標テーブル）
- `id` (PK)
- `title` (目標内容)
- `is_active` (現在選択中の目標かどうかを示す真偽値)

### Post（YWT活動記録テーブル）
- `id` (PK)
- `done` (やったこと)
- `learned` (わかったこと)
- `next_action` (次やること)
- `created_at` (作成日時)
- `goal_id` (FK, Goalテーブルとのリレーション)

## 💡 工夫したポイント・学んだこと
- **1対多のリレーション実装**: SQLAlchemyを使って「1つの目標に対して複数のYWTが紐づく」構造を設計し、目標の切り替えに連動して表示が切り替わるようにしました。
- **データ型の整合性**: データベース操作時に発生しがちな型エラー（整数型と文字列型の違いなど）を意識し、安全なデータやり取りを心がけました。
