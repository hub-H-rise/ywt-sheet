# YWT目標達成アプリ

## 概要
「達成したい目標」と、それに対する日々の活動記録である「YWT（やったこと・わかったこと・次やること）」を紐づけて管理できるWebアプリケーションです。

資格学習やプログラミング学習を継続する中で、その日に取り組むことや振り返りを一元管理したいと考え開発しました。
目標とYWTを紐づけることで、目標達成に向けた積み重ねが可視化しやすく、継続的な学習につなげやすいと考えています。

また、分かったこと(W)に実践した結果を記録することで振り返りの際に自分の行動パターンの把握につながると思います。

## 主な機能
- **目標管理(Goal)機能**
  - 新規目標の設定、アクティブな目標の切り替え
- **YWT活動記録（Post）機能**
  - やったこと（Y）、わかったこと（W）、次やること（T）の投稿・編集・削除
  - 投稿日時の自動記録（タイムゾーン考慮）
- **データ連動機能**
  - 選択中の目標に紐づくYWTだけを絞り込んで表示

## 使用技術
- **バックエンド**: Python, Flask
- **データベース**: PostgreSQL, Flask-SQLAlchemy, Flask-Migrate, psycopg
- **フロントエンド**: HTML, CSS, Jinja2テンプレート
- **環境管理**: Poetry
- **バージョン管理**: pyenv

## データベース設計（テーブル構造）
### Goal（目標テーブル)
- `id` (PK)
- `title` (目標内容)
- `is_active` (現在選択中の目標かどうかを示す真偽値)

### Post（YWT活動記録テーブル）
- `id` (PK)
- `done` (やったこと)
- `learned` (わかったこと)
- `next_action` (次やること)
- `created_at` (作成日時)
- `goal_id` (FK, Goalテーブルとのリレーション)

##  工夫したポイント
- **目標ごとにYWTを管理できる構造を実装**:

SQLAlchemyを用いて、各目標に対応するYWTを管理できるデータ構造を設計しました。さらに目標の切り替え機能を実装し、複数の目標を並行して管理できるようにすることで、日常生活・勉強・仕事など幅広い用途に対応できる設計としました。

- **ユーザビリティを意識したルーティング設計**:

ルート(`/`)から目標設定画面(`/goal`)への誘導や、目標登録から活動記録(`/create`)へ自然につながる導線を作り、ユーザーが迷わず操作できるようにしました。
